# 终端舞台功能基线

版本：v0.5.0（ACP助手、统一设置与历史工作区；隔离验收不代表所有真实模型或公开发送验收）。用户操作见[官网手册](https://danmu.elazer.wang/guide/)。
上游行为参考：[`yaocccc/bilibili_live_tui`](https://github.com/yaocccc/bilibili_live_tui)
数据口径参考：[Bilibili API Collect · 直播间基本信息](https://socialsisteryi.github.io/bilibili-API-collect/docs/live/info.html)、[Bilibili API Collect · 直播间信息流](https://socialsisteryi.github.io/bilibili-API-collect/docs/live/message_stream.html)

> 上游仓库未提供 LICENSE。本项目只按公开界面和外部行为独立实现，不复制其源码。B 站网页接口不是公开稳定 SDK；Adapter 通过严格字段解析和契约测试显式暴露漂移，不用默认值掩盖未知状态。

## 产品边界

DANMU 是独立的免费终端产品。平台协议由 Rust `bilibili` Adapter 负责；标准事件、会话投影和日志由 `domain` 与 `persistence` Module 负责。Cookie、CSRF 和原始平台 payload 不进入终端配置、领域事件或归档。

## Rust TUI 验收矩阵

| 能力 | 验收标准 |
| --- | --- |
| 房间连接 | 位置参数、`--room` 或 TOML 配置均可进入；短号解析为真实房间号 |
| 启动数据加载 | 本地会话逆序尾读，账号与房间并发；无固定动画等待。自检后立即进入主界面，全量归档索引和镜像后台加载，不共享实时写入的镜像锁，不在耗时扫描时持有源文件锁；固定前缀只导入完整记录，新弹幕持续写原件并分批补齐索引。日志追加读取尾序号，旧无序号归档仅首次计数 |
| 本地历史回看 | 正常退出或异常中断后，按房间读取最近一份含有效消息的归档；跳过较新的空/仅临时活动会话，最多240条。新会话、新计数，旧消息标↶，不进入Bridge或AI队列，不续写旧归档；空/复用ID的不同历史正文仍保留 |
| 历史弹幕 | 连接前拉取最近弹幕，连接期间每5秒用历史窗口补偿WebSocket漏包；history/live按平台事件ID及作者、内容、类型去重，补偿消息按服务端时间进入实时视图；主动发送以主播身份回流确认，并抑制延迟到达的遮罩昵称副本 |
| 实时事件 | 覆盖弹幕、礼物、大航海、SC、进场、点赞、关注、分享、PK、抽奖、房管、开停播和系统事件；礼物兼容 JSON `SEND_GIFT`、protobuf `SEND_GIFT_V2` 与 `COMBO_SEND`；V2 的 GiftItem 字段 9 是交易 ID、字段 12 是批次 ID。同一作者、批次和礼物就地累计，不同批次或盲盒结果保持独立；逐笔数量按交易 ID 去重，与批次累计值取较大值而非相加，重复明细、较旧汇总和恢复后重放不重复计数。保留原消息位置并同步重点消息；旧版本已归档的重复行不追溯改写 |
| 自动重连 | 使用 1、2、4、8、15、30 秒有界退避；不递归、不 panic；状态栏显示下次延迟 |
| 房间信息 | `getRoomBaseInfo` 首次加载并每 30 秒刷新：请求失败自动重试一次，字段级合并新响应，缺失或解析失败字段沿用上次成功值；`room_id` 是真实房间号，`uid`/`uname` 是主播身份，`title` 是直播间标题，`parent_area_name`/`area_name` 是父子分区，`live_time` 是中国标准时间的本次开播时刻；`live_status` 严格映射 0=未开播、1=直播、2=轮播，未知值直接报契约变化；刷新失败不终止弹幕连接 |
| 直播间资料 | `/room title [文本]`与`/room cover [本地路径]`省略值时打开编辑器；带值时先验证当前B站主账号就是房主，再提交并等待平台真实回执。标题或封面被平台受理后仍可能待审核，只显示准确状态，不宣称已对外展示；local模式拒绝写入 |
| 实时计数 | 输入框右侧仅保留 ◉ 累计看过、♥ 累计点赞、● 当前在线，移除本次弹幕计数。在线采用登录态 getOnlineRank.data.onlineNum；失败重试一次并沿用上次成功值，无值显示 --。getRoomBaseInfo.online 与心跳 op=3 是人气值，不作在线人数；指标后台加载，不阻塞主界面 |
| 登录 | TUI内“B站账号与直播间 → 手动发送账号 → 登录B站”（`/settings account`）使用低纠错紧凑二维码并按空间居中；空间不足不裁切，resize后恢复。`danmu --login`保持标准终端二维码；登录态只写TUI独立BilibiliAccount/session.json，Unix 0600，不使用钥匙串；local模式拒绝账号操作 |
| 发送弹幕 | 当前执行层每段最多40个Unicode字素，优先标点、其次空白，再按字素硬拆；上一段受理及回显确认后，间隔1200ms发送下一段；失败/未知停止后续，不重复既有公开实验 |
| 文本编辑 | 输入框按终端显示宽度自动换行，最后一行始终保持 `╰─ 输入内容  ─╯` 形态，内容后以空白填充、仅两端保留短横线；最多显示四行并跟随光标滚动；支持左右方向键、Home/End、删除、`Ctrl+A/E/U/W`；`Ctrl+C` 或 `/quit` 安全退出并恢复终端状态 |
| 键盘消息选择 | `Shift+↑/↓` 移动回复目标并使用低刺激前景色强调；选择期间新消息不改变目标；`Enter` 在光标处插入 `@用户名 `；`Esc` 取消 |
| 鼠标历史浏览 | 主界面使用终端的alternate-scroll，滚轮转为↑↓，每个方向键移动一条正文消息，跳过进场与点赞；从回复选择切换到滚轮时沿用当前消息位置并取消回复选择；新消息到达保持阅读锚点。高对比状态条持续显示历史模式、Esc 返回提示、新消息数量与可选倒计时；Esc、End 或向下滚回底部恢复实时跟随；Esc 不退出 TUI |
| 文字复制 | 主界面不捕获鼠标，直接原生拖选任意文字后使用终端复制快捷键（macOS ⌘C）；不进入独立页面，不改草稿、回复目标或发送权限。菜单/弹窗仍捕获滚轮，回到主界面立即释放。Ctrl-C仍为退出 |
| 历史空闲返回 | 默认手动；`/settings reading`“外观与显示”中的“自动回到最新弹幕”持久保存秒数到TOML，0关闭；CLI覆盖仅本次启动。键盘及应用接收到的滚轮重置计时，消息到达不重置；保留草稿，弹窗期间暂停计时；主界面原生选区由终端维护 |
| 临时互动提示 | 固定显示在弹幕框底边，不进入正文、不改变历史浏览或回复选择；空闲时立即显示，至少稳定 2 秒。只保留当前批次与下一批分类摘要，每类最多 3 个姓名，多余用“等”，优先减少姓名数量、最后才截断超长单名；可靠用户 ID 相同才合并同批重复互动，不按昵称合并身份。进场优先，足够宽时附加点赞姓名摘要；进场批次最长展示 5 秒、点赞 3 秒。待展示条目按事件时间分别在 5 秒、3 秒后失效，历史回放不触发通知，已替换或被抑制的批次不补播；关闭姓名后不泄露名字。临时活动与其他消息各保留最多 240 条，展示合并不改变原始日志和计数，历史翻页不计入临时活动 |
| 应用通知 | 操作提示、进度、警告和错误统一显示在弹幕框下方、输入框上方，不进入弹幕内容区域，也不参与弹幕滚动与回复选择 |
| 外观 | 内置`shisui`、`catppuccin-mocha`、`tokyo-night`、`gruvbox-dark`高对比True Color主题；`/settings reading`“外观与显示”或`/display theme`打开主题选择并按Enter保存；主题页可重载`themes.json`；主题不改变功能与布局 |
| 单/多行 | `single_line` 配置与 `--single-line` 控制元信息和正文是否同行；正文按终端宽度换行 |
| 显示开关 | `/settings reading`“外观与显示”或`/display names on\|off`、`/display time on\|off`修改用户名、时间并保存show_name/show_time到TOML；省略值打开选择器，保存失败不应用 |
| 消息布局 | Tab或`/display layout chat\|list`切换并保存chat_layout；省略值打开选择器，保存失败不应用。待审条按实际候选与当前送达反馈显隐；主题仍由themes.json管理 |
| 主播身份 | 依据直播间主播 UID 使用独立用户名颜色；正文保持事件语义色 |
| CJK 与 Emoji | 按 Unicode 字素编辑和分段，按终端显示宽度定位光标；过滤常见 IME 格式字符；已知 B 站短码映射语义 Emoji，平台图片表情使用通用 Unicode Emoji 降级显示 |
| 实时状态分层 | 沿用原版两行布局：左侧 ● LIVE / ○ OFFLINE / ◉ ROTATING，标题居中、右侧时长；第二行主播左对齐，OBS/MIC 右对齐。OBS ● 绿连接、红未连接；MIC ◉ 声音公开、○ 静音、? 未知。LIVE 每 500ms 显隐并占位，时长不闪烁。输入左侧 ↑ / 旋转标记 / ✓ / ? / × 表示待输入、发送核实、送达、未确认、拒绝；右侧仅 ◉、♥、●。主播正文前保留 ♚ 皇冠 |
| 会话归档 | 每个新会话写独立journal.jsonl；结束时生成summary.md与snapshot.json。总菜单提供“搜索归档”关键词编辑及“重点消息”；/find 无参数同样打开编辑器，带关键词直接搜索，/pin保留为快捷方式 |
| OBS 配置 | `danmu --configure-obs`配置主机、端口、场景、麦克风和密码；TUI中`/obs config host [host]`、`port [port]`、`mic [名称]`、`password`及场景配置均可达。可选值省略时打开编辑器/选择器；给值时校验并在真实保存回执后更新。密码写独立`obs-password`文件（Unix 0600），`OBS_API_PASSWORD`可临时覆盖 |
| OBS 控制 | `/obs`、`/obs status`、`/obs connect`、`/mute`、`/unmute`、`/scene [名称]`、`/obs start`、`/obs stop`；异步操作显示进度，认证、密码和连接失败保留原因；场景和输入候选读取 OBS 真相；停播弹窗默认取消，确认后倒计时3秒，Esc可在请求发出前取消；停播不退出TUI |
| 麦克风电平 | 原生 OBS 事件约每 50 毫秒输入一次，Adapter 聚合为 10 Hz；显示限制在 -60 至 0 dBFS，快速上升、平滑回落；输入框顶栏宽度充足时显示数值和彩色区间，窄屏降级为短条，静音显示 `MIC MUTE`，断连时隐藏 |

## 架构门禁

- TUI 与商业 GUI 使用完全隔离的配置、凭据和会话日志命名空间。
- TUI 只写自己的 JSONL Journal，不读取或修改商业 GUI 的日志。
- TUI 独立拥有直播连接；商业 GUI 不安装、包含或启动 TUI。
- TUI 退出、终端崩溃或 OBS 不可用不能删除既有会话日志。
- 所有新增平台字段先在 Adapter 中按已核验的原始 key 严格解析并转换为标准模型，再进入平台无关领域层；字段缺失或枚举未知必须暴露契约错误，不得猜测或静默置零。
- TUI 仅显示所配置麦克风的单路电平，不包含播放器、完整直播画布、音频混音、录制、Replay Buffer 或 OBS 场景编辑能力。

| 配置投影 | 当前值与保存反馈；原生参数完整ACK才更新，当前值重选不提交，未知项只读。普通操作无二次确认；编辑保存失败留内容。方案单次保存十字段，差异在说明展开，只能暂停且无在途时用，不改模型/身份/自动模式/续用意图。独立扫码当前Ready自动校验提交，迟到/同主UID/保存失败保留旧账号 |

| 取消/恢复 | session/cancel观察原prompt终态、超时清退自有进程组；load回放不入候选，resume不接回放；迟到不跨场/轮 |
| 逐消息状态 | SDK发起本轮才给选中消息Processing黄；无答Finished灰、真实生成失败Failed红；完整EndTurn且没有assistant message按无答处理，保持连接处理下一批，畸形输出仍拒绝。暂停/结束生成收束，原候选/在途/实际发送结果优先；不跨场/轮、不以候选冒充成功 |
| AI停机诊断 | 异常关闭统一停机、撤权、要求重建且保留首因；正常预算轮换不记异常。初始化、参数恢复、协议与资源上限错误仍停机，不自动重试/重启/授权。主界面与/diag展示原因，私有journal的assistantStopped记录时间、原生会话与原因；手动继续不保留误导性的旧停机提示 |
| 观众记忆 | 按本房间归档和当前观众UID检索，相关旧互动优先、再补近期；每人最多3条、全批最多8条/3KiB、每条240字符，与话题检索共享4KiB并计入24KiB/64KiB输入限制。跨场和重启恢复，不按昵称认人、不猜缺失身份，不把历史当指令或永久事实 |
| 发送回声与诊断 | POST前等待UI完成回声匹配器注册，极速回声不再早于注册；真实无回声仍Uncertain且不重发。autoReply/send_completed保留请求、UID、诊断和分段结果；写盘失败暂停助手但不改写真实送达。畸形候选的assistantStopped含160字符转义预览 |
| Agent退出 | /quit、Ctrl-C、Unix SIGINT/SIGTERM/SIGHUP及终端错误统一await自有Runner清退，再退出runtime；保留原始错误。重复start复用连接，重建先停旧组再启动新组。只管理自有进程组，SIGKILL、主动脱组后代和外部独立Agent不作回收保证 |
| 权限/互斥 | 默认候选，发送权独立；暂停保留候选与草稿。缺回显只隔离本条及未发尾段，不重发、不撤全场许可；真实传输错误等安全撤权保留。有限修复不得跨过撤权/过期/换场；同内置caller防双驱动，不全局封禁 |
