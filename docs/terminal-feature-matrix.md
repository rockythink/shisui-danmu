# 终端舞台功能基线

日期：2026-07-20
上游行为基线：[`yaocccc/bilibili_live_tui`](https://github.com/yaocccc/bilibili_live_tui)

> 上游仓库未提供 LICENSE。本项目只按公开界面和外部行为独立实现，不复制其源码。

## 产品边界

终端舞台是拾穗弹幕台的另一种前端，不是第二套直播产品。平台协议仍由
`BilibiliDanmu` Adapter 负责，问题识别、提问队列和会话日志仍由 `DanmuCore`
负责。Cookie、CSRF 和原始平台 payload 不进入终端配置、领域事件或归档。

## 上游兼容矩阵

| 能力 | 上游行为 | 拾穗验收标准 |
|---|---|---|
| 房间连接 | `-r` 或 TOML 房间号 | 启动参数、配置和 App 当前房间均可进入；短号解析为真实房间号 |
| 历史弹幕 | 连接时拉取最近弹幕 | history/live 无缝展示并沿用三秒去重规则 |
| 实时事件 | 弹幕、礼物、舰长、进场、通知 | 全部覆盖，并保留 SC、点赞、关注、分享、PK、抽奖、房管等拾穗扩展事件 |
| 自动重连 | 断线提示后重启连接 | 有界退避状态机，不递归、不 panic，界面明确显示次数和延迟 |
| 房间信息 | 标题、ID、分区、在线、关注、开播时长 | 首次加载并约每 30 秒刷新；失败不终止弹幕连接 |
| 在线榜 | 在线贡献榜 Top 50，前三名徽章 | 信息主题与聊天室主题可见，支持滚动/裁切 |
| 发送弹幕 | Cookie 登录后发送 | 未登录时输入框直接显示 `/login`；输入 `/` 可选择 `/login` 打开授权窗口、`/logout` 清除 TUI 独立登录态；启动前仍可使用 `danmu --login`；登录 Helper 诊断写入 `~/Library/Application Support/cc.ss-data.ShisuiDanmuTerminal/login-diagnostic.log`，不记录凭证或平台内容 |
| 长消息 | 每 20 字一段，间隔一秒 | 保留单段平台限制，发送前展示分段结果并顺序发送；失败停止后续分段 |
| 草稿编辑 | 方向键浏览输入历史 | 输入历史不再占用方向键；左右方向键、Home/End、删除与 Emacs 风格编辑快捷键继续用于输入框 |
| 编辑快捷键 | `Ctrl+U` 清空 | 支持；`Ctrl+C` 安全退出并恢复终端状态 |
| 键盘弹幕选择 | 无 | 输入普通草稿时，`↑/↓` 在可见用户名的弹幕间移动并高亮，选中项始终保持可见；`Enter` 在当前光标处插入 `@用户名 ` 并回到输入框，`Esc` 取消选择并回到输入框；选择期间冻结消息投影，Slash 命令建议打开时方向键仍只移动建议项；不启用终端鼠标报告模式，并通过关闭 Alternate Scroll Mode 阻止滚轮被终端转换为方向键 |
| Chatroom 主题 | 房间信息、榜单、消息、发送框 | 行为等价的 `chatroom` 主题 |
| Pure 主题 | 纯消息和发送框 | 行为等价的 `pure` 主题 |
| Simple 主题 | 单行房间信息、消息、发送框 | 行为等价的 `simple` 主题 |
| Info 主题 | 消息、进场、礼物分栏 | 行为等价的 `info` 主题；宽屏三栏、窄屏两栏 |
| 浅色主题 | 米白、冷白、鼠尾草绿、浅绯背景，深色正文 | `paper`（别名 `light`）、`porcelain`、`sage`、`blush`，均使用拾穗增强布局 |
| 单/多行 | 相同用户和类型可聚合显示 | `singleLine` 配置与启动参数控制元信息和正文首行是否同行；消息正文始终按终端显示列宽自动换行，不以省略号截断 |
| 时间显示 | 可隐藏时间 | `showTime` 配置与启动参数覆盖 |
| 用户名显示 | 可隐藏用户名 | `--hide-name`、`show_name = false` 或 `/names hide` 隐藏消息、提问、重点消息、榜单和事件摘要中的用户名；`/names show` 恢复 |
| 消息布局 | 普通信息流 / 聊天窗口 | 默认信息流；TUI 内按 `Tab` 即时切换，顶部显示当前布局；聊天布局中昵称和时间、正文分两排，消息之间留空行，主播靠右、观众靠左 |
| 配色 | 时间、名字、内容、边框、信息、榜单、背景 | 每个主题自带独立 True Color 调色板；主播身份仅通过用户名专属色区分，正文保持内容/事件颜色且不添加文字前缀；占位 uid 不参与全局昵称映射，脱敏实时弹幕只在公开历史得到内容/时间/模式唯一匹配时恢复全名；支持配置文件和启动参数覆盖，非法颜色回退到主题默认值 |
| CJK 修正 | 重启进程修正 locale | 原生 UTF-8 输入、中文宽度计算和安全裁切；硬件光标由终端按实际字宽推进，并移除 IME 标点提交可能附带的不可见格式字符 |
| OBS 遥控 | 无 | `danmu --configure-obs` 安全配置 WebSocket 与 Keychain 密码；TUI 运行中可用 `/obs config password` 进入不回显、不进入命令历史的安全输入并原位替换 Keychain 密码，也可用 `/obs connect` 连接稍后启动的 OBS、以 `/obs config mic <输入>` 即时切换和持久化麦克风控制目标；输入框用 `/obs` slash command 控制 status、mute/unmute、scene、start、stop；场景和输入候选直接读取 OBS 现有列表；输入 `/` 展示实时过滤的命令、参数和说明，`↑/↓` 选择、`Tab` 补全、`Enter` 执行、`Esc` 关闭建议；停播需再输入 `/obs confirm`，可用 `/obs cancel` 取消；命令不会发送为弹幕 |

## 拾穗增强层

兼容主题之外增加默认 `shisui` 主题：

- 待回答、回答中、已回答和跳过问题；
- 高优先级、稍后回答、完成并下一题；
- 重点上屏；
- 当前会话归档和历史回放；
- Ghostty 透明背景、可选 shader、动态标题及高优问题通知；
- 非 Ghostty 终端保持完整功能，只关闭 Ghostty 专属视觉增强。
- OBS 状态栏宽屏显示连接、推流、场景和麦克风，窄屏压缩标签，极窄窗口仍保留底部输入框。
- 每次启动检测 `obs-cli`；缺失时先在普通终端提示不可用能力并询问是否通过 `uv tool install obs-cli` 自动安装，拒绝后继续启动核心弹幕功能。
- 停止 OBS 推流后 TUI、B 站连接和弹幕会话继续运行；录制和 Replay Buffer 不受影响。

## 架构门禁

- TUI 与商业 GUI 使用完全隔离的 Application Support、Keychain 和会话日志命名空间。
- TUI 只写自己的 JSONL Journal，不读取或修改商业 GUI 的日志。
- TUI 独立拥有自己的直播连接；商业 GUI 不再安装、包含或启动 TUI。
- TUI 退出、终端崩溃或 OBS 不可用不能删除其既有会话日志。
- 所有新增平台字段先转换为 Adapter 自有模型，再进入平台无关领域层。
