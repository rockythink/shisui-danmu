## 产品边界

DANMU 是独立的免费终端产品。平台协议由 Rust `bilibili` Adapter 负责；标准事件、会话投影和日志由 `domain` 与 `persistence` Module 负责。Cookie、CSRF 和原始平台 payload 不进入终端配置、领域事件或归档。

共享业务实现位于公开 MPL `runtime`；默认 `tui` feature 保留免费终端入口，`--no-default-features --lib` 不编译终端栈。私有 Mac 宿主通过 UniFFI `DanmuCoreFFI` 接入同一运行层，不把商业授权门槛加入免费核心。2026-10-19 的隔离 QA 已观察到房间连接、旧档案 UID、审核页、面板事件与未读差值；贴边物理交互、系统通知、负载和真实平台/模型/OBS 推流仍未验收。

2026-10-19 隔离 Mac QA 只观察到部分入口：房间连接、旧档案 UID、审核页、380pt 面板、未读差值、原生菜单和安全退出。矩阵其余 Mac 行有原生入口源码，但未逐项在真实窗口点击验收。贴边物理交互、系统通知投递、真实平台/模型/OBS 推流和 30 分钟满负载仍未通过。

已在隔离窗口观察到的 Mac 入口：`NativeLiveView` 房间连接与事件列表，`SessionArchiveView` 旧档案 UID，`AssistantReviewView` 审核页，`UnreadStore` 差值与 `DanmuDeskCommands` 原生菜单。2026-10-20 已收敛为一个 420pt `DanmuMonitorWindow`，正文和输入默认 18pt，使用原生毛玻璃；设置与审核通过附属界面打开，不再保留第二个工作台。隔离 QA 已观察到隐藏后重开仍保留草稿及 3 条未读、正常退出 0、模型请求 0、OBS 停止请求 0、旧档案原件 hash 不变。GUI 命令搜索已移除，操作由按钮、表单、分类设置菜单与快捷键承载；开发版此前实测菜单直达 AI 设置、文本框输入、切换 OBS 与系统设置。共享错误指引使用暂停、OBS 设置与诊断，不要求输入 TUI 命令；TUI 自身的命令入口保留。系统通知默认关闭，需用户开启并授权；默认 SC、上舰和助手致命故障，普通弹幕只增加未读，实际系统投递仍未验收。其余矩阵行的原生源码入口尚未逐项点击，不能记为通过。

Mac 负载实测（35 分钟，被脚本截止）：注入 22100 条合成事件，约每秒 10.5 条，低于每秒 100 条验收目标；显示列表封顶 248，未读累计 22000，RSS 30–73 MB 有界，核心未停，模型 0 请求，OBS 0 停止。瓶颈为 journal 每条 `sync_data` 与整场快照；保持耐久性语义不变。

## 架构门禁

- TUI 与商业 GUI 使用完全隔离的配置、凭据和会话日志命名空间。
- TUI 只写自己的 JSONL Journal，不读取或修改商业 GUI 的日志。
- TUI 独立拥有直播连接；商业 GUI 不安装、包含或启动 TUI。
- TUI 退出、终端崩溃或 OBS 不可用不能删除既有会话日志。
- 所有新增平台字段先在 Adapter 中按已核验的原始 key 严格解析并转换为标准模型，再进入平台无关领域层；字段缺失或枚举未知必须暴露契约错误，不得猜测或静默置零。
- TUI 仅显示所配置麦克风的单路电平，不包含播放器、完整直播画布、音频混音、录制、Replay Buffer 或 OBS 场景编辑能力。
