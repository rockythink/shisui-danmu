# 拾穗弹幕台使用独立仓库

日期：2026-07-20

## 决策

拾穗弹幕台作为与商业 GUI 并列的独立产品，使用独立目录、独立 Git 历史和独立 Rust crate。

## 原因

- 产品只解决弹幕会话、直播监控和重点上屏，不承担完整直播画布职责。
- 独立仓库可以保持发布节奏、包标识、数据目录和商业化策略独立。
- 直播助手当前工作区存在未提交改动，直接复制会混入来源不清的实现和画布技术债。

## 后果

- 初期允许按行为迁移少量代码，但不共享源码目录或 Git 历史。
- 两个产品发现共同能力后，只有在出现两个真实 Adapter 或调用方时，才提取共享 package。
- 迁移期间必须分别验证两个产品，不能用其中一个仓库的构建结果替代另一个。
